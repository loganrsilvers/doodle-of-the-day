# doodle-of-the-day
<img width="1737" height="982" alt="Doodle of the Day" src="https://github.com/user-attachments/assets/10b89c47-dab6-484d-86ea-b3e063f46bcc" />
Doodle of the Day is a collaborative web application that allows authenticated users to contribute drawings to a shared online database each day. 

* Customizable user profiles
* PHP authentication with SQL data storage
* Likes, Undos, Report features
